# Taiga-APM-Projekt
In diesem Repo befinden sich alle wichtigen Dateien, die im Zuge der Projektarbeit zur Einrichtung von Taiga auf einem Hochschulserver entstanden sind.
Die entstandene Seite kann unter http://apm.hs-emden-leer.de/ abgerufen werden.
---
## Enthaltene Dateien:
- Taiga_Installation.md: Vollständige Installationsanleitung zur Einrichtung von Rootless Docker + Taiga auf Hochschulserver (ohne Verwendung eines gemounteten NAS)
- Taiga_Backup.md: Anleitung zum lokalen Sichern und Wiederherstellen der Taiga Projekte, um diese auf neuem Server später wieder installieren zu können
- taiga-backup.zip: Backup des aktuellen Demoprojektes "APM Demo Project - Real-Life Pacman Robot"
- Taiga_Maileinrichtung.md: Anleitung zur Befähigung Taigas E-Mails zu senden (mit eigener Hochschulmail) -> *ungetestet und benötigt weitere Recherche*
- Taiga_Installation_NAS.md: Vollständige Installationsanleitung zur Einrichtung von Rootless Docker + Taiga auf Hochschulserver (inklusive Verwendung eines gemounteten NAS) -> *Aktuell so nicht Funktionsfähig, Verwendung von mnt/nas konnte nicht erfolgreich hergestellt werden, hierfür wäre weitere Recherche/Entwicklung nötig*
